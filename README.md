# Ziyana TV

Android TV home launcher starter for Singer 43G22GOTV (Android/Google TV).

## Build APK
1. Open the **Actions** tab.
2. Select **Build Ziyana TV APK**.
3. Press **Run workflow** (or wait for a push build).
4. Open the completed run and download the **Ziyana-TV-APK** artifact.
5. Extract the ZIP to get `app-debug.apk`. The repository now builds the TV launcher only.

## Install and select as Home
Install the APK on your TV. Press the Home button and select **Ziyana TV**. If Android TV offers an Always option, choose it to make Ziyana TV the default Home app. You can change this later in Settings > Apps > Default apps > Home app (menu wording varies by TV).

## Current features
- Android HOME and Leanback launcher intent filters
- Remote/D-pad focusable home cards
- Installed app list and launch action
- Android Settings and Wi-Fi shortcuts
- Dark, purple-accented starter interface

## Important
This is an initial starter build, not a finished Apple TV clone. Anime character artwork, advanced animations, voice-search integration, app tiles/icons and device-specific testing are not included yet. Google TV may restrict replacing its Home screen or certain system actions.
